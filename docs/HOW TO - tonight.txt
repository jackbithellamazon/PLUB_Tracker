PLUB v1.00 — Export everything / Import everything
==================================================

WHAT'S NEW
- PLUB now OPENS ON A TO-DO PAGE: "<name>, before we go online" — 3 steps, one big
  green Export button. Becki just follows it. It stops showing once she ticks
  "I've sent it to Jack" and presses "All done".
- Easier to read: every grey label lifted (was ~4:1 on black, now ~7:1).
- "Export everything" button at the bottom of the left sidebar (both apps).
  One file = every idea, product, task, supplier, session and setting from
  Unique Bundles AND Private Label on that laptop.
- "Import everything" puts a file back exactly as it was (saves a safety copy first).
- Also brings everything from v0.95 (bulk add ideas, supplier directory, Becki's fixes).

STEP 0 — belt and braces (1 minute, BEFORE uploading)
- On the CURRENT live version, you and Becki each open the ··· menu (top right)
  and press "Download backup" — once in Unique Bundles, once in Private Label.
  Keep those files.

STEP 1 — upload
- GitHub > PLUB_Tracker > docs > Add file > Upload files
- Drag these 3 files in (index.html, ub.html, pl.html) — the files, not the folder.
- Commit. Wait ~1 minute, then reload PLUB with Cmd+Shift+R (forces the new version).
  It opens on the to-do page and the sidebar says v1.00. Becki does the same reload.

STEP 2 — export (you AND Becki, each on your own laptop)
- Open PLUB — it opens on the to-do page. Press the big green "Export everything".
  After that, exporting is ONE CLICK any time: the green "Export everything" card at
  the bottom of the sidebar, or ··· (top right) > Export everything — in every page.
- File lands in Downloads:  PLUB everything - <name> - <date time>.json
- The page shows what's in the file — check it looks like your work.
- Becki sends you her file (WhatsApp / email / Drive). Keep both safe.
- DON'T import Becki's file on your laptop — that REPLACES your data.
  Both files get combined when we go online.

If anything ever goes wrong: Export everything > Import everything > pick the file.
